method

how a prediction works

step 1 · encode

features become angles

Each input feature rotates a qubit: RY(x · scale). Data literally rotates qubits.

step 2 · entangle

trainable layers + CNOT

Trainable RY/RX rotations, then a CNOT ties the qubits together so the model can't split into two independent halves.

step 3 · read out

measure ⟨Z⟩

The expectation value of qubit 0 lands in [−1, +1] — that's the prediction.

training

parameter-shift rule

No backprop. Nudge each angle ±90°, watch the loss move, step downhill — the exact same rule works on real quantum hardware.

experiment 02

the C port

The edge-AI endgame: export_c.py turns the trained model into a C header, and firmware/main.c is the whole simulator ported to plain C — no Python, no NumPy, just math.h. Same 8 weights, same predictions, six decimal places of agreement with the Python version. It compiles clean with -Wall.

make && ./pocketq  ← that's the whole install
